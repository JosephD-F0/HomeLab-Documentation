# Joseph's IT Home Lab

## About This Repository
This repository documents my hands-on home lab work built for 
CompTIA A+ exam preparation and entry-level helpdesk readiness.

Every project is documented in IT ticket format mirroring real 
enterprise helpdesk procedures. Labs are performed inside a 
Windows 10 Pro virtual machine running on Oracle VirtualBox.

---

## Lab Environment
- **Hypervisor:** Oracle VirtualBox
- **Guest OS:** Windows 10 Pro
- **Host OS:** Windows 10
- **VM Storage:** D Drive — 300GB available
- **Purpose:** CompTIA A+ prep and helpdesk skill development
